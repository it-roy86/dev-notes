# 모바일 반응형 화면 적용

> 작성일: 2026-05-05
> 참고 프로젝트: meal-management-front

---

## 왜 모바일 대응이 필요했나?

어머니가 휴대폰으로 접속해야 하기 때문에
모바일 화면에서도 사용하기 편하게 개선했어요.

---

## 핵심 개념

### 미디어쿼리 (Media Query)

화면 크기에 따라 다른 CSS를 적용하는 방법이에요.

/* 768px 이하 (모바일) */
@media (max-width: 768px) {
  /* 모바일용 스타일 */
}

### PC vs 모바일 요소 전환

PC에서는 테이블, 모바일에서는 카드로 전환해요.

/* PC에서 모바일 카드 숨기기 */
.mobile-list {
  display: none;
}

/* 모바일에서 테이블 숨기고 카드 보이기 */
@media (max-width: 768px) {
  .table { display: none; }
  .mobile-list { display: flex; flex-direction: column; }
}

### CSS 주석 주의사항

CSS에서는 // 주석을 사용할 수 없어요!
반드시 /* */ 방식을 사용해야 해요.

/* 올바른 CSS 주석 */
// 이건 CSS에서 에러가 나요!

## 화면별 적용 내용

### 1. DashboardView.vue

PC: 메뉴 카드 3열 가로 배치
모바일: 메뉴 카드 1열 세로 배치 + 아이콘/텍스트 가로 배치

### 2. SettingView.vue

PC: 회사/팀 목록 테이블
모바일: 카드 형태로 표시

카드 구성:
- 회사명 (굵게)
- 사업자번호, 이메일, 상태 (작은 글씨)
- 수정/팀 버튼

주의: 테이블과 모바일 카드를 둘 다 template에 작성하고
CSS로 화면 크기에 따라 보이고 숨기는 방식이에요.

### 3. MealView.vue (식사 현황 조회)

PC: 7컬럼 테이블
모바일: 기록별 카드 표시

카드 구성:
- 날짜 + 합계 금액 (상단)
- 회사명 + 팀명 (중간)
- 중식/석식/총 인원 (하단)

### 4. SettlementView.vue (월별 정산)

PC: 6컬럼 테이블
모바일: 팀별 카드 표시

카드 구성:
- 팀명 + 합계 금액 (상단)
- 중식 인원/금액 | 석식 인원/금액 (나란히)
- 합계 카드 (파란 배경으로 강조)

.modal {
  width: 90%;

}

## 핵심 정리

1. 미디어쿼리로 768px 기준 PC/모바일 분기
2. 테이블은 PC용, 카드는 모바일용으로 각각 작성 후 CSS로 전환
3. CSS 주석은 반드시 /* */ 사용 (// 사용 시 Vite 에러 발생)
4. flex-direction: column으로 세로 정렬
5. display: none / display: flex로 요소 보이고 숨기기
