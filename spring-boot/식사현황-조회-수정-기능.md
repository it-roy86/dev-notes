# 식사 기록 수정 기능 개발 정리

> 작성일: 2026-05-21
> 참고 프로젝트: meal-management, meal-management-front

---

## 왜 만들었나?

일일 식사 입력 시 잘못 입력한 경우 수정할 방법이 없었어요.
식사 현황 조회 화면에서 잘못된 기록을 선택해서 수정할 수 있도록 기능을 추가했어요.

---

## 개발 순서 (기능별 개발 방식)

1. MealView.vue 화면에 수정 버튼 및 모달 추가
2. Spring Boot 수정 API 개발
3. Vue.js API 연동
4. 테스트

---

## Step 1 - MealView.vue 화면 수정

### PC 테이블

thead에 관리 컬럼 추가
tbody에 수정 버튼 추가
colspan 7 → 8 변경

### 모바일 카드

mobile-record-footer에 수정 버튼 추가
counts와 버튼을 좌우로 배치

### 수정 모달 구성

읽기 전용 정보 (수정 불가):
- 날짜
- 회사명
- 팀명

수정 가능 항목:
- 중식 인원
- 석식 인원

---

## Step 2 - Spring Boot API 개발

### MealRecordUpdateRequest DTO

lunchCount: 수정할 중식 인원
dinnerCount: 수정할 석식 인원

날짜/회사/팀은 수정 불가 (변경 필요 시 삭제 후 재입력)

### MealRecordService - updateMealRecord()

처리 순서:
1. id로 기존 식사 기록 조회
2. 팀 단가 가져오기
3. 새 인원으로 총 인원/금액 재계산
4. DB 저장

총 금액 재계산 공식:
totalAmount = (lunchCount x lunchPrice) + (dinnerCount x dinnerPrice)

### MealRecordController

PUT /api/meal-records/{id}

요청:
{
  "lunchCount": 15,
  "dinnerCount": 8
}

응답: MealRecordResponse (수정된 기록)

## 숫자 입력 화살표 제거

브라우저 기본 스타일인 숫자 입력 화살표를 CSS로 제거했어요.
직접 만든 CSS가 아니라 브라우저 기본값이라 추가로 덮어써야 해요.

적용 파일:
- MealView.vue (수정 모달)
- MealInputView.vue (식사 입력)

```css
/* Chrome, Safari, Edge */
input[type="number"]::-webkit-outer-spin-button,
input[type="number"]::-webkit-inner-spin-button {
  -webkit-appearance: none;
  margin: 0;
}

/* Firefox */
input[type="number"] {
  -moz-appearance: textfield;
}
```

## 핵심 정리

1. 날짜/회사/팀은 수정 불가 → 잘못된 경우 삭제 후 재입력
2. 중식/석식 인원 수정 시 총 인원/금액 자동 재계산
3. 저장 후 목록 자동 새로고침
4. PC 테이블 + 모바일 카드 모두 수정 버튼 적용
5. 숫자 입력 화살표는 CSS로 제거 (브라우저 기본값 덮어쓰기)
